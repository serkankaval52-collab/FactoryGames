# AŞAMA 0A — Hat Kurulumu (tek seferlik)

**Girdi:** geçilmiş sonda; mevcut hesaplar (bireysel Play + Apple, ikisinde de
yayında oyun, aktif AdMob); kullanıcının Ek C Bölüm-1 tavanları.

Adımlar sıralıdır; her adımın kanıt artefaktı vardır. Tıkanan adım "Geri kenarı"
kuralına düşer.

## Adımlar

1. **MAĞAZA ERİŞİM TEYİDİ** (insan, ~30 dk): Play Console'da yeni uygulama
   taslağı aç → Üretim sekmesi erişilebilir mi; App Store Connect'te yeni app
   kaydı açılabiliyor mu. Kanıt: ekran görüntüleri →
   `docs/factory/verification/01-magaza-erisim/`. Teyit yoksa DUR: insana
   eskalasyon (hesap/12×14 gündemi yeniden açılır).
2. **FATURA TEYİDİ** (insan, 5 dk): GitHub billing sayfasında "public repo =
   hosted runner ücretsiz" teyidi → `docs/factory/verification/02-billing/`.
3. **ŞABLON İSKELET** (otonom): oyun şablonu — `Packages/factory.core`
   (bootstrap loader, JSON loader, telemetry writer, analitik/reklam
   sarmalayıcı stub'ları), tek Bootstrap sahnesi, `StreamingAssets` JSON'ları,
   `.github/workflows/` (`lint`, `secret-scan`, `test`, `android`),
   `ProjectVersion.txt` (6000.3.x pin). Çıktı: `templates/` dizini.
4. **HELLO-BUILD KANITI** (CI): boş iskeletle Android APK yeşil + iOS
   xcodeproj macOS runner'da derleniyor. Kanıt: Actions run linkleri.
5. **KASITLI İHLAL TESTİ** (otonom): geçici branch'te ~300 GameObject'li sahne
   + sahte secret içeren commit → lint ve secret-scan KIRMIZI vermeli. Kanıt:
   iki kırmızı run linki; branch silinir. Kırmızı gelmediyse CI düzeltilir,
   max 3 tekrar.
6. **UNITY CI LİSANSI** (insan, ~15 dk): unity-activate akışı → `.alf` →
   license.unity3d.com'a yükle → `.ulf` → `UNITY_LICENSE` secret'ı. Kanıt:
   lisanslı CI test koşusu yeşil.
7. **STANDART DOSYALARI** (karma): `standartlar/` altına — fikir standardı;
   çeşitlilik defteri (mevcut oyunlar ilk kayıt, iki mağaza); hesap-deseni
   envanteri (mevcut oyunların hücreleri işli); rubrik şablonu; pre-mortem
   taksonomisi; PR şablonları; `FALLBACK.md` (her MCP işinin CLI eşdeğeri);
   telemetry şeması; **Ek C kaynak dosyası — Bölüm-1 tavanlarını İNSAN
   doldurur**.
8. **HALKA HAVUZU v0** (insan toplar): ≥2 tur × 5–10 kişi. Gizlilik kuralı:
   repoda yalnız `tester_id` + rol sayaçları tutulur; isim/iletişim public
   repoya GİRMEZ. Çıktı: `standartlar/halka-envanteri.md` (id tablosu).
9. **SOSYAL HESAPLAR** (insan): fabrika TikTok + YouTube hesapları açıldı; ad
   standardı kayıtlı; erişimler secrets'ta. Kanıt satırı.
10. **MCP KONFİG** (otonom): resmî sunucu kurulu; sahne-düzenleme araçları
    kapatılabiliyorsa kapalı; FALLBACK doğrulaması (bir CLI komutu koşturulup
    çıktısı kaydedildi).

**0A geçiş kriteri:** 1–10 tik; hello-build ve ihlal kanıtları linkli;
envanterlerde mevcut oyun kaydı; Ek C Bölüm-1 dolu.
**Yürüten:** karma (işaretli adımlar insan, kalan otonom).
**Geri kenarı:** bir adım 3 denemede kapanmazsa → insana eskalasyon ve hat
duraklar; kurulum tek seferlik olduğundan tur limiti yoktur.
