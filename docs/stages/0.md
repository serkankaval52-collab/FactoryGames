oyun, aktif AdMob); kullanıcının Ek C Bölüm-1 tavanları.

**0A çıktı (hat kurulumu):** şablon repo (`factory.core` iskeleti; CI: lint,
secret-scan, test, Android); CLAUDE.md iskeleti; FALLBACK.md; telemetry şeması; PR
şablonları (post-mortem/öğrenme); pre-mortem risk taksonomisi; rubrik şablonu;
çeşitlilik defteri + hesap-deseni envanteri — **mevcut oyun ilk kayıt olarak işlenmiş
ve Ek A sayımına dahil**; Ek C kaynak dosyası (kullanıcı doldurur); dış-halka havuzu
(≥2 tur × 5–10 kişi) kuruldu; çapraz tanıtım şablonu (HTTP interstitial, varsayılan
KAPALI — Aşama 10 + kullanıcı onayıyla açılır); Unity CI lisansı (.ulf secret);
secrets düzeni.
**0A doğrulamalar (kilitleme anında):** yeni uygulama taslağında üretim sekmesi açık

(lint ve secret-scan gerçekten yakalıyor); envanterde mevcut oyun kaydı; halka
havuzu listelendi.
**0B önkoşul:** Ek C Bölüm-1 tavanları dolu (Bölüm-2 boş kalabilir — para önkoşul
değildir).
**0B çıktı (pilot koşu):** Aşama 1–10'u yarı-elle geçen ilk oyun iki mağazada
review'a GÖNDERİLDİ (kabul şart değil); aşama bazında darboğaz kaydı; standartlar
damıtılıp v1.0 etiketlendi; öğrenme PR'ı FactoryGames'e açıldı.
**0B geçiş:** gönderim kanıtı + darboğaz PR'ı merge + belgeler v1.0.
