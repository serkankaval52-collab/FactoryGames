# AŞAMA 0B — Pilot Koşu (tek seferlik)

**Önkoşul:** 0A kapalı + Ek C Bölüm-1 dolu (Bölüm-2 boş kalabilir — para önkoşul
değildir).

## Protokol (mikro adımlar)

1. **Konsept:** Aşama 1 standartlarıyla üretilir (yasak listesi, 3 kart, defter
   kontrolü dahil) ama seçim **açık insan onayıyla** yapılır — veto penceresi
   pilotta geçmez.
2. **Tam tur:** Aşama 1→10 yarı-elle koşulur. Her aşama çıkışında darboğaz
   satırı yazılır: `{aşama, süre, Ek B beklentisi, sapma, sebep, çözüm}`.
   Zaman damgaları telemetry'den otomatik düşer; satırı yalnız yorum kısmıyla
   insan tamamlar.
3. **Standart muafiyeti yok ama öncelik sırası var:** kapılar koşulur; yarı-elle
   demek geri kenarların insana bağlanması demek, kapıların atlanması değil.
4. **Gönderim:** sosyal organik kit dahil tam sürüm; iki mağazada review'a
   GÖNDERİLDİ (kabul şart değil).
5. **Kapanış:** darboğaz PR'ı + öğrenme PR'ı FactoryGames'e (Sözleşme-7);
   standartlar damıtılıp **v1.0** etiketlenir; PIPELINE.md sürümü v1.0 olur.

**Çıktı:** review gönderim kanıtı; darboğaz PR'ı (merge); öğrenme PR'ı (merge);
standartlar v1.0 etiketi.
**Yürüten:** karma (insan yoğun; üretim otonom, kararlar açık onaylı).
**Geri kenarı:** pilot oyun raflanırsa hat ölmez — dersler işlenir, yeni pilot
Aşama 1'den başlar. İkinci pilot hakkı var; üçüncüye karar insandadır.
