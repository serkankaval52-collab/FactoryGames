# AŞAMA 5 — Halka Kapısı (parlatmadan önce nitel kanıt)

**Girdi:** çökmezliği kanıtlı gri kutu; dış-halka havuzu; analitik bağlı kapalı
track dağıtımı.
**Çıktı:** üç sonda sorusunun yazılı cevapları (ikinci kez açar mıydın / nerede
bıraktın / ne beklerdin), N=5–10, 48–72 sa; kapalı track'ten **küçük-n gerçek
D1/D2** (analitik halkaya bağlı — kalibrasyon dosyasına bedava veri);
GEÇ veya **RAF** kararı kaydı.
**Yürüten:** karma — halka insan; dağıtım, toplama, tablolama otonom.
**Geçiş kriteri:** ≥5 tamamlanmış sonda formu + analitik satırları + yazılı karar.
**Geri kenarı:** RAF = mezar değil raf: konsept kartı kanıtıyla defterde durur, yeni
veriyle Aşama 1'e geri girebilir. Kalibrasyon dolmadan (3 koşu) kalıcı öldürme yok.
"İyileştirip halkaya tekrar sunma" hakkı konsept başına **1 kez**, hedefi Aşama 4.
Kalibrasyon sonrası bu aşama kalıcı öldürebilir: post-mortem + defter güncellemesi.
**Rotasyon kuralı:** bu aşamada oynayan testçi, aynı oyunun Aşama 8'deki \* eksenlerini
(ilk izlenim) puanlayamaz — B2 tazeliği korunur; iki tur havuzdan dönüşümlü.
