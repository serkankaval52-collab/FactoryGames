# Yasak Liste Arşivi — `YYYY-MM.md` (Aşama 1 ön-adım 1'in çıktısı)

Aylıktır: o ayın ilk Aşama 1 koşusunda üretilir, sonraki koşular yeniden okuma
yapmaz — arşiv o ayın tek kaynağıdır (Sözleşme-2). Kaynak: Play + App Store
ücretsiz-oyun sıralamalarının web okuması; web yoksa insan kapısı (tek cümle) ile
10 satır alınır.

Dosya formatı:
- okuma tarihi + kaynak URL'leri (iki liste) — bu satırlar `- ` ile BAŞLAMAZ (kura
  ayrıştırıcısı `- ` gördüğü her satırı klişe sayar; 2026-08'deki adet=12 gürültüsünün
  dersidir — havuz eşleşmesi olmadı, zarar yok ama kayıt kirlenir),
- 10 klişe mekanik: `- **kısa ad** — kanıt (hangi listede kaçıncı sırada görüldü)`
  satırları; kura script'i (tools/kura.py) bu satırları ayrıştırır (M1).

Aylar üst üste birikince tekrar eden klişelerin örüntüsü görünür; bu örüntü Ek A
katalog genişletme görevine girdi olur.
